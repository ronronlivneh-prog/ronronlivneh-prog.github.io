# Video and Keyword SEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Optimize Ron Livneh's local videos and strengthen the approved Hebrew search intents across existing site pages.

**Architecture:** Keep the static HTML structure and public URLs. Media optimization happens in place, while HTML gains visible context, poster images and structured data; tests treat the rendered files as the public contract.

**Tech Stack:** Static HTML/CSS, Node test runner, Python unittest, FFmpeg/FFprobe.

**Spec:** `docs/superpowers/specs/2026-11-26-video-seo-design.md`

## Global Constraints

- No hidden SEO text or keyword stuffing.
- No unverified facts or dates.
- No en dashes or em dashes in public copy.
- Existing canonical and media URLs remain stable.

## Review Focus

- Video markup without a usable poster must fail the media contract test.
- Structured video data missing required Google fields must fail the SEO test.
- Keyword placement must remain page-specific and visible.
- Compressed video files must remain playable and smaller than the originals.
- Changed pages must retain unique canonical metadata and sitemap coverage.
