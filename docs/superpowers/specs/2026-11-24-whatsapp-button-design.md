# WhatsApp Contact Button Design

## Intent

Make the direct WhatsApp action more noticeable in every Ron and Erez contact section without introducing a loud new color block that competes with the existing page design.

## Approved design

- Keep the button background white.
- Add a recognizable green WhatsApp icon before the label.
- Add a subtle green border, slightly larger dimensions and a soft shadow.
- Keep the label dark for strong contrast and preserve the existing speaker-specific wording and prefilled WhatsApp messages.
- Apply the same treatment to all nine profile and lecture pages, including mobile layouts.

## Approaches considered

- Solid dark-green button: more prominent and accessible, but visually heavier. Rejected after reviewing the mockup.
- White button with green accents: selected because it remains consistent with the current contact panel while making WhatsApp easier to identify.

## Constraints

- Do not change form submit buttons or other site buttons.
- Use a local icon asset and no new third-party dependency.
- Preserve accessible focus behavior, link destinations and existing text.
