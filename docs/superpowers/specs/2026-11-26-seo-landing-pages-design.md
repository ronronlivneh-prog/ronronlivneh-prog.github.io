# SEO landing pages design

## Goal

Create two useful, visible landing pages that answer high-intent searches from HR, culture, welfare and conference organizers while strengthening the authority of Ron and Erez's existing profile and lecture pages.

## Pages

1. `/ron-livneh/ai-lectures-for-organizations/`
   - Focus: הרצאות בינה מלאכותית לארגונים, הרצאות AI, מדע, טכנולוגיה ועתיד העבודה.
   - Present Ron as an accessible, human-centered speaker rather than a technical trainer.
   - Link to Ron's three main lectures, her profile and contact section.

2. `/erez-livneh/innovation-futures-for-organizations/`
   - Focus: הרצאות חדשנות ועתידנות לארגונים, סדנאות חשיבת עתיד וייעוץ להנהלות.
   - Present Erez's science, entrepreneurship and organizational innovation background.
   - Link to Erez's three lectures, profile, workshops and contact section.

## Content and design

- Use the established visual system, speaker colors, header, footer and typography.
- Keep all SEO copy visible and useful to visitors.
- Use real stage imagery already stored locally.
- Include clear audience fit, outcomes, formats and selection guidance.
- Use no en dash or em dash anywhere.
- Do not claim invented customers, outcomes, testimonials or statistics.
- Keep contact conversion on the existing speaker page forms rather than duplicating forms.

## Discovery

- Add contextual links from the homepage organization section and each speaker profile.
- Add both URLs to `sitemap.xml` with the release date `2026-11-26`.
- Add unique title, description, canonical, Open Graph tags, `Service` and `BreadcrumbList` structured data.

## Verification

- Extend the Node SEO tests to require both pages, their metadata, visible intent copy, internal links and sitemap entries.
- Run the full Node and Python test suites.
- Preview representative desktop and mobile layouts before deployment.
